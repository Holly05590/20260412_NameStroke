手機加入 App

操作手冊

✦
開始之前

把「姓名學筆劃查詢」加到手機主畫面後，點一下圖示就能開啟，用起來像一個 App，不必每次重新輸入網址。整個過程約 1 分鐘，不需要到 App Store 或 Google Play 下載。

請先準備：

  • 網址：https://holly05590.github.io/20260412_NameStroke/
  • 瀏覽器：iPhone / iPad 請用 Safari；Android 請用 Chrome
  • 網路：第一次開啟需要連上網路（筆劃字庫與字型由網路載入）
iPhone / iPad（Safari）
  1. 開啟 Safari，在網址列輸入上面的網址，等頁面載入完成。
  2. 點畫面下方的 分享 按鈕（方框加向上箭頭）。iPad 的分享按鈕在右上角。
  3. 在選單中往下滑，點 加入主畫面。
  4. 名稱預設為「姓名學筆劃鑑定」，可以改短一點，例如「姓名學」。
  5. 點右上角 加入，主畫面就會出現圖示。

若使用 Chrome 等其他瀏覽器（iOS 16.4 以上），也可從分享選單找到「加入主畫面」；找不到時請改用 Safari。

Android（Chrome）
  1. 開啟 Chrome，在網址列輸入上面的網址，等頁面載入完成。
  2. 點右上角的 ⋮（三個點）選單。
  3. 點 加到主畫面。部分手機顯示為「安裝應用程式」或「新增至主螢幕」。
  4. 可以修改名稱，然後點 新增。
  5. 若跳出「加到主畫面」確認視窗，再點一次 新增，或長按圖示拖到想放的位置。

Samsung 手機若使用內建的 Samsung Internet：點右下角 ≡ 選單 → 新增頁面至 → 主螢幕。

開啟與使用

在主畫面點「姓名學」圖示即可開啟，用法與網頁版相同：

  1. 輸入姓、名一（必填）與名二（可留空），結果會自動顯示。
  2. 在流年運程圖上方輸入出生年月日（民國年），可看到虛歲、太歲星與發動年齡。
  3. 點「清　空」可重新輸入。
  4. 點標題下方的色點可切換主題風格，下次開啟會記得你的選擇。
常見問題
問題解決方式
找不到「加入主畫面」iPhone 請改用 Safari；分享選單要往下滑到底。Android 請確認用的是 Chrome。
用 LINE、Facebook 開啟連結時沒有選項App 內建的瀏覽器不支援，請點右上角選單，選「以瀏覽器開啟」後再操作。
圖示是網頁截圖或字母，不是 App 圖示等頁面完全載入後再加入；仍不對就刪除圖示重加一次。
開啟後筆劃顯示「—」或字型怪怪的確認手機有連上網路，關掉後重新開啟。
想看到最新版本不必重新加入；重新開啟即可。若仍是舊版，從上方往下拉重新整理。
想移除長按主畫面圖示 → iPhone 點「移除 App」→「刪除」；Android 拖到「移除」或點「解除安裝」。
